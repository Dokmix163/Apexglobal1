# Управление контентом товаров

Этот файл содержит инструкции по редактированию данных о товарах для сайта ApexGlobal.

## Структура

Все данные о товарах теперь находятся в отдельном файле: **`src/data/products.js`**

Этот файл содержит:
- `plantArt` - пути к изображениям заводов
- `heroHotspots` - интерактивные точки на главном изображении  
- `bitumenTanks` - массив битумных ёмкостей
- `products` - массив асфальтобетонных заводов

## 1. Редактирование карточек товаров

Откройте файл `src/data/products.js` и найдите нужный товар в массиве `products` или `bitumenTanks`.

### Доступные поля для редактирования:

- **`name`** - название товара
- **`description`** - краткое описание (отображается в карточке)
- **`fullDescription`** - полное описание (отображается в модальном окне)
- **`features`** - массив ключевых особенностей
- **`capacity`** - производительность (т/ч) или объём (м³)
- **`type`** - тип комплекса
- **`badges`** - бейджи (например: `[{ type: 'top', text: 'Топ продажа' }]`)

### Пример:

```javascript
{
  id: 'apexcore-320',
  enabled: true,
  name: 'ApexCore 320',
  description: 'Краткое описание для карточки',
  fullDescription: 'Подробное описание для модального окна',
  features: [
    'Особенность 1',
    'Особенность 2'
  ],
  // ... остальные поля
}
```

## 2. Редактирование фотографий

### Основные изображения товара:

Измените массив `images`:

```javascript
images: [
  './assets/my-product-1.jpg',  // Локальное изображение
  'https://example.com/image.jpg',  // Внешнее изображение
  plantArt.hero  // Использование готового пути
]
```

### Фотографии компонентов ("Что входит в комплекс"):

Измените поле `image` в массиве `includesDetailed`. Чтобы временно скрыть карточку из модального окна комплектации, добавьте `enabled: false`:

```javascript
includesDetailed: [
  {
    title: 'Сушильный барабан',
    description: 'Описание компонента',
    image: './assets/component-image.jpg',  // Измените путь здесь
    enabled: true  // Установите false, чтобы скрыть элемент
  },
  // ... другие компоненты
]
```

### Кнопки "Что входит в комплекс" (`includes`)

Каждый элемент отображается как кнопка с иконкой в модальном окне продукта. Можно временно отключить кнопку, установив `enabled: false`:

```javascript
includes: [
  { icon: '⚙️', text: 'Сушильный барабан', enabled: true },
  { icon: '🔥', text: 'Горелка ApexFire', enabled: false }  // кнопка не будет показана
]
```

### Типы путей к изображениям:

1. **Локальные файлы**: `'./assets/my-image.jpg'`
2. **Внешние URL**: `'https://example.com/image.jpg'`  
3. **Готовые пути**: `plantArt.hero`, `plantArt.cobalt` и т.д.

## 3. Включение/выключение товаров

Чтобы скрыть товар с сайта (не удаляя данные), установите `enabled: false`:

```javascript
{
  id: 'apexcore-320',
  enabled: false,  // Товар НЕ будет показан на сайте
  name: 'ApexCore 320',
  // ... остальные поля
}
```

Чтобы товар снова отобразился, установите `enabled: true` или просто удалите это поле (по умолчанию товары включены).

## 4. Добавление нового товара

1. Скопируйте структуру существующего товара
2. Измените `id` на уникальный (например: `'new-product-2025'`)
3. Установите `enabled: true`
4. Заполните все поля
5. Добавьте товар в конец массива `products` или `bitumenTanks`

### Пример:

```javascript
export const products = [
  // ... существующие товары
  {
    id: 'new-product-2025',  // Уникальный ID
    enabled: true,
    name: 'Новый завод',
    capacity: 250,
    capacityCategory: 'medium',  // 'low', 'medium' или 'high'
    type: 'Стационарный комплекс',
    badges: [],
    description: 'Краткое описание',
    fullDescription: 'Подробное описание',
    features: [
      'Особенность 1',
      'Особенность 2'
    ],
    includes: [
      { icon: '⚙️', text: 'Компонент 1' },
      { icon: '📊', text: 'Компонент 2' }
    ],
    includesDetailed: [
      {
        title: 'Компонент 1',
        description: 'Подробное описание компонента',
        image: './assets/component.jpg'
      }
    ],
    specs: [
      { label: 'Производительность', value: '250 т/ч' },
      { label: 'Мощность', value: '20 МВт' }
    ],
    pdfSpec: '#',  // Ссылка на PDF спецификацию
    images: [
      plantArt.hero,
      plantArt.cobalt
    ]
  }
];
```

## 5. Сохранение изменений

1. Отредактируйте файл `src/data/products.js`
2. Сохраните файл
3. Обновите страницу в браузере

**Важно**: Не забывайте делать резервные копии перед большими изменениями!

## Доступные иконки для `includes`:

- `'⚙️'` - шестерёнка (оборудование)
- `'📊'` - график (система дозирования)
- `'🔥'` - огонь (горелка)
- `'🌿'` - экология (фильтрация)
- `'💻'` - компьютер (система управления)
- `'📦'` - коробка (силосы)
- `'🛢️'` - бочка (ёмкость)
- `'🌡️'` - термометр (контроль температуры)
- `'🔄'` - циклы (перемешивание)
- `'🛡️'` - щит (защита/изоляция)
- `'🚚'` - грузовик (мобильная платформа)
- `'♻️'` - переработка (РАП)

## Структура файла products.js:

```
products.js
├── plantArt (объект с путями к изображениям)
├── heroHotspots (массив интерактивных точек)
├── bitumenTanks (массив битумных ёмкостей)
│   └── [товар 1, товар 2, ...]
└── products (массив асфальтобетонных заводов)
    └── [товар 1, товар 2, ...]
```
